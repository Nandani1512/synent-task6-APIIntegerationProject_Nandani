# Screenshots

Put your app screenshots in this folder so the main `README.md` can display them.

Use these exact filenames (the README links to them):

| Filename | What to capture |
|----------|-----------------|
| `dashboard.png` | Top of the page: hero + stats + skills + repositories |
| `activity.png`  | The contribution heatmap + commit-activity chart |
| `themes.png`    | Light vs dark theme (or a single theme) |
| `resume-pdf.png`| A page of the exported résumé PDF |

**Capture on Windows:** press **Win + Shift + S** to snip a region, then paste into
Paint (or any editor) and **Save As → PNG** here. PNG is preferred for crisp UI.

Once added: `git add screenshots && git commit -m "Add screenshots" && git push`
